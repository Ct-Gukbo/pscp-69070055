# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย

## 1. ข้อมูล OJ

หมายเลข/ชื่อโจทย์ OJ:

```text
OJ3476 - [LEARNING LOGS] CuteCat CuteFox
```

OJ submission ID ถ้ามีการส่งแล้ว:

```text
https://ijudge.it.kmitl.ac.th/submissions/681440/overview
```

สถานะ OJ:

```text
Pass
```

เวลาที่ใช้คิดและทำโจทย์ด้วยตนเอง:

```text
1-3 hours
```

เลือกหนึ่งข้อ:

```text
0-15 minutes
15-30 minutes
30-60 minutes
1-3 hours
3-6 hours
6-24 hours
1-3 days
4-7 days
1-4 weeks
More than 4 weeks
```

วิธีนับเวลา:

- นับเฉพาะเวลาที่ตั้งใจทำโจทย์นี้ด้วยตนเองจริง ๆ
- เริ่มนับตั้งแต่ตอนที่อ่านโจทย์ครั้งแรก
- ไม่นับเวลาพัก กินข้าว เรียน นอน เวลาที่ทำโจทย์อื่น หรือเวลาที่ไม่ได้ทำโจทย์นี้
- ถ้าใช้ AI ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อน prompt แรกที่ถาม AI
- ถ้าถามเพื่อน TA หรือผู้สอน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือครั้งแรก
- ถ้าใช้ทั้ง AI และความช่วยเหลือจากคน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือจากภายนอกครั้งแรก ไม่ว่าจะเป็น AI หรือคน
- ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้นับเวลาถึงก่อนเขียน `submission.md`
- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์สั่งให้ทำอะไร:
ให้เรารับข้อมูลรายชื่อสัตว์เลี้ยงพร้อมรหัสประจำตัวมาคัดแยกประเภทว่าเป็น "แมว" (Cat) หรือ "จิ้งจอก" (Fox) แล้วนับจำนวนของแต่ละประเภท จากนั้นให้นำรายชื่อมาเรียงลำดับตามตัวเลขรหัสประจำตัวจากน้อยไปมาก นอกจากนี้ยังมีกติกาพิเศษ (Easter Egg) คือ ถ้าในระบบไม่มีแมวหมายเลข 1 (Cat01) และไม่มีแมวชื่อ Garfield ให้เพิ่ม Garfield เป็น Cat01 โดยอัตโนมัติ และในทำนองเดียวกัน ถ้าไม่มีจิ้งจอกหมายเลข 1 (Fox01) และไม่มีชื่อ Fubuki ก็ให้เพิ่ม Fubuki เป็น Fox01 เข้าไปด้วย

Input (ข้อมูลที่ต้องป้อน):

ใส่จำนวนบรรทัดของข้อมูล (n)

บรรทัดต่อๆ มา ใส่ข้อมูลสัตว์เลี้ยงในรูปแบบข้อความที่มีหน้าตาเหมือน Dictionary จับคู่ "ชื่อ" กับ "รหัส" เช่น {"Mochi": "Cat02"} จำนวน n บรรทัด

Output (ผลลัพธ์ที่โปรแกรมต้องแสดง):

พิมพ์สรุปจำนวนแมว Cat : [จำนวน]

พิมพ์สรุปจำนวนจิ้งจอก Fox : [จำนวน]

พิมพ์รายชื่อแมวพร้อมรหัส (เรียงตามหมายเลขรหัสจากน้อยไปมาก)

พิมพ์รายชื่อจิ้งจอกพร้อมรหัส (เรียงตามหมายเลขรหัสจากน้อยไปมาก)

Constraints (ข้อสังเกต/เทคนิคเพิ่มเติม):

ข้อมูลที่รับเข้ามาเป็นตัวอักษร (String) แต่มีรูปแบบเป็นโครงสร้าง Dictionary โปรแกรมจึงใช้โมดูล ast.literal_eval เพื่อแปลงข้อความให้กลายเป็น Dictionary ของ Python จริงๆ ทำให้ดึงข้อมูล "ชื่อ" (Key) และ "รหัส" (Value) มาใช้งานต่อได้ง่าย

ในการเรียงลำดับรหัส โปรแกรมจะใช้วิธีตัดตัวอักษร 3 ตัวแรก ("Cat" หรือ "Fox") ทิ้งไปก่อน แล้วแปลงเฉพาะส่วนที่เป็นตัวเลขด้านหลังให้เป็นจำนวนเต็ม (Integer) เพื่อใช้เป็นเกณฑ์ในการเรียงลำดับให้ถูกต้องตามหลักคณิตศาสตร์ (เช่น 2 ต้องมาก่อน 10)
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: อ่านค่าจำนวนบรรทัดของข้อมูล (n) และเตรียมกล่อง Dictionary ว่างๆ ชื่อ pets ไว้เก็บข้อมูลรวม
Step 2: วนลูปรับข้อมูลจำนวน n ครั้ง แต่ละครั้งจะแปลงข้อความให้เป็น Dictionary แล้วดึงข้อมูล "ชื่อ" และ "รหัส" มาเก็บรวบรวมไว้ใน pets
Step 3: ดึงข้อมูลส่วนที่เป็น "รหัสประจำตัว" (Values) ทั้งหมดออกมารวมเป็น Set ชื่อ codes เพื่อเตรียมใช้ตรวจสอบ
Step 4: ตรวจสอบว่าในระบบมีรหัส "Cat01" หรือชื่อ "Garfield" หรือไม่ ถ้าไม่มีทั้งคู่ ให้แอบเพิ่มข้อมูล {"Garfield": "Cat01"} เข้าไป
Step 5: ตรวจสอบว่าในระบบมีรหัส "Fox01" หรือชื่อ "Fubuki" หรือไม่ ถ้าไม่มีทั้งคู่ ให้แอบเพิ่มข้อมูล {"Fubuki": "Fox01"} เข้าไป
Step 6: คัดกรองและแยกประเภทข้อมูล โดยดึงรายการที่รหัสขึ้นต้นด้วย "Cat" ไปไว้กลุ่ม cats และรหัสที่ขึ้นต้นด้วย "Fox" ไปไว้กลุ่ม foxes
Step 7: นำกลุ่มแมวมาจัดเรียงลำดับ โดยแปลงตัวเลขหลังคำว่า "Cat" ให้เป็นจำนวนเต็ม แล้วเรียงจากน้อยไปมาก
Step 8: นำกลุ่มจิ้งจอกมาจัดเรียงลำดับเช่นเดียวกัน โดยแปลงตัวเลขหลังคำว่า "Fox" แล้วเรียงจากน้อยไปมาก
Step 9: พิมพ์สรุปจำนวนประชากรแมวและจิ้งจอกที่แยกไว้ใน Step 6
Step 10: วนลูปพิมพ์ "ชื่อ : รหัส" ของกลุ่มแมวทีละบรรทัด ตามด้วย "ชื่อ : รหัส" ของกลุ่มจิ้งจอกทีละบรรทัด ตามลำดับที่จัดเรียงไว้เรียบร้อยแล้ว
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
เหมือนวิธีเเรกเลย

```

## 7. ความช่วยเหลือจากคน / การร่วมมือ

ได้ถามเพื่อน TA ผู้สอน หรือบุคคลอื่นเพื่อขอความช่วยเหลือในโจทย์นี้หรือไม่

```text
No
```

ถ้าใช่ ให้อธิบายสั้น ๆ ว่าได้รับความช่วยเหลือแบบใด

ตัวอย่างที่อนุญาต:

- อธิบายความหมายของโจทย์
- อธิบาย concept การเขียนโปรแกรม
- ให้ hint เกี่ยวกับแนวทาง
- คุยเรื่อง debugging
- คุยเรื่อง test cases
- ช่วยอธิบาย error message

สิ่งที่ไม่อนุญาต:

- คัดลอก code ของผู้อื่น
- ส่ง solution ของผู้อื่น
- ขอให้ผู้อื่นเขียน solution ให้
- ใช้ OJ submission ของผู้อื่น
- ขอให้ผู้อื่นส่ง OJ แทน
